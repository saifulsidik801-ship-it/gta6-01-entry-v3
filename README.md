MARISOL BAY — take the city, district by district. An original open-world crime game: Milo Kade came back to Marisol Bay with nothing but a borrowed coupe and a crew that owes him. Eight districts, one patrol that never sleeps, and a helicopter that always finds you. Drive, steal cars, lose the heat, run jobs for the crew, and buy your way up from wheelman to tide boss.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game plays in a desktop browser from static files, no network request. `node main.ts` (or `MAKEFUN_OUTPUT_DIR=out node main.ts`) builds the entry dossier.

## Controls

WASD move · mouse look · E steal a car · click to fight · TAB weapons · M map · U garage · P pause · Q radio station · V radio play/pause · J start the next job

## What is inside

- A full grid city: 8 named districts, lit tower blocks, palms, beach, sea, pier ferris wheel, billboards, traffic and pedestrians
- Police that respond to a 0–5 wanted level, with named response units, tactics, roadblocks — and a police helicopter with a searchlight from wanted 3
- 8 story jobs with staged objectives, crew abilities (Mira, Lio, Kiki), portrait dialogue and a radio with 4 fictional stations
- A HUD with mission panel, police response panel, weapon slots, crew cards, minimap, speed, condition, rank/RP and respect
- A pause menu with mission list and stats, a full map + stats screen, and the Hillside Garage workshop with upgrades and Weapons & Gear
- Saves in localStorage (3 slots)
